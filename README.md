# Voxel Palace · 体素宫殿（Three.js）

可直接运行的 3D 体素（Voxel）风格中国古典建筑群场景，风格类似 Minecraft 方块拼接。打开页面即进入场景并自动环绕展示全貌，无需任何操作。

## 运行方式

需要 Node.js ≥ 18（推荐 20+）。

```bash
npm install     # 安装依赖（three + vite）
npm run dev     # 启动开发服务器
```

打开浏览器访问终端中显示的地址（默认 <http://localhost:5173>），首页即为宫殿建筑群场景。

```bash
npm run build   # 产出静态文件到 dist/
npm run preview # 本地预览构建产物
```

## 页面

| 地址 | 场景 |
| --- | --- |
| `/` (index.html) | 体素中式建筑群（本 README 主场景） |
| `/landscape.html` | 体素山水（山脉 + 瀑布 + 穿云，上一版场景） |

两页通过左上角链接互相跳转。

## 布局与建筑

中轴对称院落，中轴动线：**山门 → 庭院 → 主殿 → 宝塔**，共 7 座建筑：

- **主殿**：体量最大，位于中轴核心；三重汉白玉台基 + 回廊柱列 + **重檐庑殿顶**（金黄色琉璃瓦），正面丹陛台阶
- **配殿**（东西各一）：对称分列主殿前方两侧，面朝中轴，**歇山顶**绿琉璃瓦
- **山门**：场地最南端入口，三门洞，庑殿顶金瓦
- **钟楼 / 鼓楼**：山门前东西对峙——钟楼为歇山顶，鼓楼为攒尖顶
- **宝塔**：中轴最北端，五层密檐，灰色瓦 + 攒尖顶塔刹

## 风格细节

- **屋顶**：飞檐翘角——檐口角部起翘 + 各层角脊线；庑殿顶 / 歇山顶（含山花）/ 攒尖顶三种形制，正脊两端吻兽
- **结构**：斗拱层（额枋 + 出挑），红色立柱，石阶与垂带栏杆，台基须弥座
- **门窗**：朱红金钉大门、槛窗、楼阁层明窗
- **点缀**：汉白玉华表、石狮一对、青铜香炉（鼎）、中轴两侧灯笼（夜间发光并闪烁）、院墙周匝、松柏与庭院树

## 环境与光影

- 晨昏（黄昏）低角度暖色定向光，PCF 软阴影覆盖全场景
- 渐变黄昏天穹 + 暖色雾，远景没入暮色
- 地面：庭院棋盘铺装、中轴御道石板 + 牙子、院外草地泥土噪点过渡
- 无 GPU 的环境（软件渲染）自动降级：降分辨率、关闭阴影

## 性能

全部建筑与场地体素合批为单个 InstancedMesh（约十万级实例、一次 DrawCall），灯笼为第二个小 InstancedMesh。普通核显即可稳定 ≥30fps。

## 项目结构

```
index.html            宫殿场景页（首页）与 HUD
landscape.html        山水场景页
vite.config.js        Vite 多页入口配置
src/palace/main.js    渲染器 / 黄昏天穹 / 灯光 / 相机 / 主循环
src/palace/site.js    场地布局：地面、院墙、御道、树木、灯笼、石狮、华表、香炉
src/palace/buildings.js 建筑生成：山门、配殿、主殿、钟鼓楼、宝塔
src/palace/parts.js   构件：台基、台阶、栏杆、墙体（门窗洞）、柱廊、斗拱、匾
src/palace/roofs.js   屋顶：庑殿顶 / 歇山顶 / 攒尖顶、檐口、翘角、脊兽
src/palace/ctx.js     体素上下文：朝向变换、批量盒填充、轮廓环遍历
src/palace/palette.js 宫殿配色（红墙 / 琉璃瓦 / 石木等）
src/                  山水场景与公共体素/噪声/配色工具（voxel.js 等）
```
